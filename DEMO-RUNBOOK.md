## What is on screen

Four dashboards, `gpu-walk-1` to `gpu-walk-4` (generated by `manifests/60-grafana/build_walkthrough.py`), kiosk, 1080p, last 10 min.
Every screen: progress strip + question | config (one line highlighted) | one chart, red vs blue | one sentence. **Next** button top right.

| Screen | Question | Chart | Config shown |
|--------|----------|-------|--------------|
| 1 | What does the GPU say? | GPU memory per pod (DCGM): flat; requests in flight (the load arriving) | dcgm-exporter `--kubernetes=true` |
| 2 | What does the server say? | KV cache % from the vLLM log, tokens/s, /metrics cross-check | the log line + the Lua match |
| 3 | Why was this request slow? | waiting vs on-GPU time per request, slowest red and blue traces | Collector `k8sattributes` `k8s.pod.name` |
| 4 | Is 8% too low? Is 90% too high? | verdict, GPU memory, KV peak, time to first token | our rule of thumb (>90%, <40%) |

The old one-screen stage dashboard `gpu-inference-obs` and the deep dive `gpu-inference-deep` stay loaded for Q&A.

## Numbers measured on the rig (Oct 16, NVIDIA A10G 24 GB on g5.xlarge, SAME traffic to both: 192 long requests each)

| | constrained (0.08) | over-provisioned (0.90) |
|--|--|--|
| GPU memory (DCGM) | 2.0 GB, flat | 20.6 GB, flat |
| KV cache (log), peak | 100% | ~31% |
| Requests running / waiting | ~49 / ~143 | ~191 / 0 |
| Tokens/s (log; /metrics agrees within ~2%) | ~9,500 | ~12,200 |
| Time to first token (average, vLLM /metrics) | ~5.9 s | ~0.08 s |
| Total request time (average) | ~7.8 s | ~6.1 s (blue runs all 192 at once, so each generates slower) |
| GPU series (cardinality, Oct 15) | 14 live, 56 after 3 restarts | |

Verdict thresholds (our rule of thumb, say so on stage): peak KV > 90% = MEMORY-CONSTRAINED, < 40% = OVER-PROVISIONED.
The Oct 15 v6 numbers (0.15, unequal traffic, 12 s vs 0.13 s) are retired: the gap came from the traffic split.

## Risks

| Risk | Fix |
|------|-----|
| Tunnel drops | `demo/start.sh` tunnels restart themselves |
| Tiles say "Waiting for the first log line" | Fluent Bit restarted since the last load: the demo load fixes it within 10 s |
| GPU nodes rotated overnight | NodePool `expireAfter: 24h`: apply the evening before. Pod names change; the story does not |
| Trace table slow | Jaeger keeps 10k traces in memory to stay fast; fallback `demo/trace.sh` |
| Grafana blank or logged out | the clean video, same screens |
