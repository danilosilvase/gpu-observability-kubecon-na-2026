Signal B · Fluent Bit + Lua

Tokens/s, parsed out of stdout.

The raw vLLM line

INFO [metrics.py:486] Avg prompt throughput: 254.6 tokens/s, Avg generation throughput: 462.7 tokens/s, Running: 0 reqs, Waiting: 0 reqs, GPU KV cache usage: 0.0%
  • tail → kubernetes filter → Lua → JSON
  • numbers become fields, pod name and namespace promoted to top level
function extract_vllm_metrics(tag, ts, record)
  local line = record["log"] or ""
  local gen = string.match(line,
    "generation throughput:%s*([%d%.]+)%s*tokens/s")
  if gen == nil then return 1, ts, record end
  record["gen_tokens_per_s"]   = tonumber(gen)
  record["kv_cache_usage_pct"] = tonumber(
    string.match(line, "KV cache usage:%s*([%d%.]+)%%"))
  -- promote pod name and namespace to the top level
  local k = record["kubernetes"] or {}
  record["pod_name"]  = k["pod_name"]
  record["namespace"] = k["namespace_name"]
  return 2, ts, record
end
Signal C · OpenTelemetry Collector

Stamp the pod name on every span.

  • vLLM: --otlp-traces-endpoint, one trace per request
  • Raw spans know the service, not the pod
  • k8sattributes resolves source IP → pod and stamps its name and namespace

Slow trace → pod name → same DCGM chart, same moment.

processors:
  k8sattributes:
    auth_type: serviceAccount
    extract:
      metadata: [k8s.namespace.name, k8s.pod.name,
                 k8s.node.name, k8s.deployment.name]
    pod_association:
      - sources: [{ from: connection }]
service:
  pipelines:
    traces:
      receivers:  [otlp]
      processors: [k8sattributes, batch]
      exporters:  [otlp/jaeger]

War stories 2 and 3

What silently broke.

GOTCHA 2

Auto Mode + GPU Operator

Auto Mode already ships the NVIDIA driver and device plugin. The Operator fights it. Run dcgm-exporter standalone.

GOTCHA 3

Fluent Bit tag prefix

Custom Tag patterns make the kubernetes filter skip metadata with one quiet log line. Your join key becomes empty. Fix: Tag kube.* + Kube_Tag_Prefix kube.var.log.containers.

LESSON

Validate the join key

Assert the pod name is present in all three pipelines in CI. We ship a 12-check script that does exactly that.

Takeaways

Steal this for your cluster.

  • One join key, the pod name and namespace, enforced on all three pipelines. Everything else follows.
  • dcgm-exporter in Kubernetes mode, bounded labels only. No arbitrary pod-label enrichment.
  • Fluent Bit + Lua turns serving logs into queryable throughput and KV-cache fields.
  • k8sattributes is the one OTel processor that makes traces joinable with GPU metrics.
  • Test the join key like you test code. Empty pod labels fail silently.
